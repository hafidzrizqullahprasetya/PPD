# Aturan Nama File Laporan Praktikum

## Format Nama File

Setiap file laporan praktikum disimpan dalam format PDF dengan pola nama berikut:

```text
[PPD]_Laporan_Pertemuan-[nomor]_[Nama]_[Kelas].pdf
```

## Data Praktikan

- Mata Kuliah: Praktikum Penambangan Data (PPD)
- Nama: Hafidz Rizqullah Prasetya
- Kelas: PL5A1

## Contoh

Untuk laporan Pertemuan 1, nama file yang benar adalah:

```text
[PPD]_Laporan_Pertemuan-1_Hafidz-Rizqullah-Prasetya_PL5A1.pdf
```

## Ketentuan Penamaan

1. Gunakan ekstensi `.pdf`.
2. Cantumkan singkatan mata kuliah `[PPD]` di awal nama file.
3. Cantumkan nomor pertemuan.
4. Cantumkan nama praktikan.
5. Cantumkan kelas.
6. Gunakan tanda hubung pada bagian nama agar nama file mudah dibaca.
7. Hindari spasi dan karakter khusus pada nama file.
