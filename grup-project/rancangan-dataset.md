*Opsi 1: Predictive Maintenance Mesin Industri (Rekomendasi)* • Judul: Prediksi Kerusakan Mesin Industri Berdasarkan Sensor Operasional Menggunakan Machine Learning (Predictive Maintenance)  
• Dataset: [https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
• Paper: Explainable Artificial Intelligence for Predictive Maintenance Applications
• Link Paper: [https://doi.org/10.1109/AI4I49448.2020.00023](https://doi.org/10.1109/AI4I49448.2020.00023)
• Task: Classification (Normal/Rusak &amp; 5 Jenis Kerusakan)
• Alasan:

- Data bersih (10.000 baris data sensor: suhu, torsi, RPM, keausan alat), ringan dieksekusi di Colab saat UTS.
- Sangat menarik saat UAS: mudah dideploy jadi web dashboard simulator monitoring mesin pabrik (Streamlit/Gradio).

*Opsi 2: Skrining Medis - Deteksi Dini Risiko Diabetes*
• Judul: Deteksi Dini Risiko Diabetes Melitus Tipe 2 Berdasarkan Gejala Klinis Awal Menggunakan Pendekatan Machine Learning
• Dataset: [https://archive.ics.uci.edu/dataset/529/early+stage+diabetes+risk+prediction+dataset](https://archive.ics.uci.edu/dataset/529/early+stage+diabetes+risk+prediction+dataset)
• Paper: Likelihood prediction of diabetes at early stage using data mining techniques
• Link Paper: [https://doi.org/10.1016/j.cmpb.2019.105055](https://doi.org/10.1016/j.cmpb.2019.105055)
• Task: Binary Classification (Positif/Negatif Risiko)
• Alasan:

- Paper bereputasi tinggi di jurnal Q1 Elsevier.
- Data kuesioner pasien riil (520 baris) dengan 16 gejala klinis awal.
- UAS sangat mudah dibuat aplikasi web form self-screening mandiri.

*Opsi 3: FinTech - Prediksi Gagal Bayar Kartu Kredit*
• Judul: Klasifikasi Risiko Gagal Bayar Nasabah Kartu Kredit Berdasarkan Riwayat Finansial Menggunakan Algoritma Machine Learning
• Dataset: [https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)
• Paper: The comparisons of data mining techniques for the predictive accuracy of probability of default of credit card clients
• Link Paper: [https://doi.org/10.1016/j.eswa.2007.12.020](https://doi.org/10.1016/j.eswa.2007.12.020)
• Task: Binary Classification (Gagal Bayar / Lancar)
• Alasan:

- Standar acuan industri perbankan dengan ribuan sitasi paper di jurnal Q1.
- Kasus riil credit scoring dengan 30.000 data riwayat keuangan nasabah.
- UAS cocok dijadikan portal simulasi credit approval analis bank.

*Opsi 4: Smart Energy - Prediksi Konsumsi Listrik Industri Baja*
• Judul: Prediksi Konsumsi Energi Listrik pada Industri Baja Menggunakan Algoritma Machine Learning Berbasis Regresi
• Dataset: [https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption](https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption)
• Paper: Efficient energy consumption prediction model for a data analytic-enabled industry building in a smart city
• Link Paper: [https://doi.org/10.1080/09613218.2021.1919904](https://doi.org/10.1080/09613218.2021.1919904)
• Task: Regression / Forecasting
• Alasan:

- Topik efisiensi energi industri modern di jurnal Taylor &amp; Francis.
- Kasus regresi time-series (35.000 data per 15 menit) dengan metrik MAE, RMSE, R².
- UAS berupa dashboard monitoring konsumsi listrik dan beban daya pabrik.
