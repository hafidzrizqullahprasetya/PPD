2. Silahkan membuat judul project yang unik untuk setiap kelompoknya. Judul project untuk setiap kelompok silahkan dituliskan di link google docs dibawah ini. Perwakilan kelompok saja yang mengisi. Pastikan dataset yang digunakan berbeda dengan kelompok lain! Jika ada dataset yang sudah dipakai kelompok lain, maka silahkan cari dataset yang berbeda!  
   https://docs.google.com/spreadsheets/d/1zWA3MPI5T1x8uDUEM0i3pLK_f8KFyMGr3n0vdoXDkMs/edit?usp=sharing

3. Silahkan mencari dataset di public repository (kaggle, uci dataset, dan lain lain):  
   a) https://archive.ics.uci.edu/datasets  
   b) https://ieee-dataport.org/datasets  
   c) https://www.sciencedirect.com/journal/data-in-brief  
   d) https://www.elsevier.com/researcher/author/tools-and-resources/research-data/open-data  
   e) https://datasetsearch.research.google.com/  
   f) https://www.kaggle.com/datasets  
   g) Dan lain-lain  

4. Dataset bisa berupa tabular, text, image, atau format lain.

5. Pastikan dataset sudah digunakan oleh penelitian sebelumnya yang dibuktikan dengan paper atau artikel ilmiah.

6. Silahkan membuat project terkait dataset tersebut. Project bisa berhubungan dengan:  
   a) Classification  
   b) Clustering  
   c) Regression  
   d) Forecasting  

7. Silahkan membuat code dengan python (google colab) untuk menyelesaikan permasalahan tersebut.

8. Silahkan membuat PPT presentasi (untuk presentasi max 10 menit per kelompok). Dalam slide presentasi, harus menjelaskan:  
   a) Judul  
   b) Pendahuluan, termasuk permasalahan yang akan diselesaikan  
   c) Metodologi  
   d) Hasil dan pembahasan  
   e) Kesimpulan  

9. Hasil project kelompok ini dipresentasikan pada saat UTS (untuk penilaian UTS), sampai dengan model evaluation.

10. Hasil project kelompok ini dipresentasikan pada saat UAS (untuk penilaian UAS), sampai dengan model deployment di aplikasi web atau mobile.

11. Jika ada pertanyaan silahkan ditanyakan di kelas atau WA Group.
